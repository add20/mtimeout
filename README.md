# mtimeout

`mtimeout`は、Go 言語で書かれた高機能なタイムアウト実行ツールです。
標準の`timeout`コマンド（GNU Coreutils）にインスパイアされていますが、ミリ秒単位の直感的な指定や、プロセスグループ管理による強力な強制終了をサポートしています。

## 特徴
- **柔軟な時間単位**: ミリ秒(`ms`)、秒(`s`)、分(`m`)、時(`h`)、日(`d`) をサポート。
- **孫プロセスのクリーンアップ**:`Setpgid`を利用し、`go run`やシェルスクリプトから起動された子・孫プロセスも残さず終了させます。
- **シンプルなシングルバイナリ**: Go なので依存関係なしにどこでも動かせます。

## インストール

```
go install github.com/your-username/mtimeout@latest
```
(または、リポジトリをクローンして`go build -o mtimeout`を実行してください)

## 使い方

```
mtimeout <duration> <command> [args...]
```

### 実行例

### 1. ミリ秒単位での制限

500ミリ秒以内に終わらない場合に強制終了します。
```
mtimeout 500ms sleep 1
```

### 2. 日単位での制限

バッチ処理などを 1 日でタイムアウトさせます。

```
mtimeout 1d ./long-running-job.sh
```

### 3. 複雑な時間の指定

1時間30分などの複合指定も可能です（Go の time.Duration 形式）。

```
mtimeout 1h30m heavy-process --task scan
```

## なぜ mtimeout なのか？

通常の`timeout`コマンドで`go run main.go`を実行しタイムアウトが発生した場合、`go`コマンド自体は終了しますが、その裏で動き出した実行バイナリ（孫プロセス）が生き残ってしまうことがあります。

`mtimeout`は、実行時に新しいプロセスグループを作成し、タイムアウト時には**プロセスグループ全体にシグナルを送信する**ため、リソースのリークを防ぐことができます。

## 終了ステータス

- コマンドが正常に終了した場合：そのコマンドの終了ステータス
- タイムアウトが発生した場合：`124`
- その他のエラー：`1`
